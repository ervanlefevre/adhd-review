ADHD Review

GitHub token

Classic token with the repo scope. If your organization enforces SAML SSO, authorize the token for it (token settings → Configure SSO). Stored only in this browser profile.

GitLab token (gitlab.com)

Scope api. Only the wrap-up needs it (your draft notes, publishing, approving): progress and navigation read the merge request page itself. Stored only in this browser profile.

Review order and groups

A file belongs to the first rule it matches; rules order is the review order. Weight scales the file's contribution to progress (default 1). Unmatched files end up in "Other".

Progress

A file counts at most this many changed lines, so one generated file does not dominate the bar.

Colour of the progress bars in the bar and the panel.

Extra space kept above a file when jumping to it (use it if GitHub's sticky toolbar hides the top of the diff).

Keyboard

Single characters; shift is part of the key (G ≠ g). Keys are ignored while typing in a field.
